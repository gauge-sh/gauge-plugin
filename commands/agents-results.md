description: Review recent Gauge Agents runs and summarize what agents struggled with
---

Use the Gauge connector (see the `gauge-agents` skill) to review
recent Gauge Agents results for the user's organization. If the user named an
organization, eval, or run, use it; otherwise ask which organization to review.

1. Read the organization's Agents summary and list its recent runs.
2. For the runs that failed or look most informative, read each run's insight.
3. Report the main friction points agents hit, which runs show them, and how
   many sessions each finding covers. Include any freshness or coverage
   warnings the connector returns.
4. Suggest one or two focused changes to the user's docs, CLI, or skill that
   would address the most common friction. Do not launch new runs without
   asking, since they use credits.
