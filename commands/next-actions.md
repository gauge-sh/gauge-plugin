Use the Gauge connector (see the `gauge-chat` skill) to list the open
actions in the user's Gauge Action Center. If the user named an organization
or category, use it; otherwise ask which organization.

1. List open actions, closest due date first, grouped by status.
2. Flag actions marked done whose verification failed or never ran.
3. Recommend the one or two actions to start with and why, using the evidence
   on each action.
4. Ask before starting any work, moving an action, or creating content.
